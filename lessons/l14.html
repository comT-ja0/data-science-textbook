생각 열기 120명의 공부 시간·수면 시간·성적이 담긴 표가 있습니다. “하루 4시간 이상 공부하는 학생은 몇 명이고, 그 학생들의 평균 성적은 몇 점일까?” 종이 표라면 한 줄씩 손가락으로 짚어 가며 세어야 합니다. 스프레드시트라면 필터 버튼을 몇 번 눌러야 하죠. 파이썬에서는 한 줄이면 됩니다. 오늘은 코딩이 처음인 사람도 따라 할 수 있도록 한 걸음씩 데이터 분석 도구를 익혀 봅시다.

1파이썬 셀 사용법과 변수 공통

이 교재의 회색 코드 상자가 파이썬 셀입니다. ▶ 실행 버튼을 누르면 코드가 위에서 아래로 한 줄씩 실행되고 결과가 아래에 나타납니다. 처음 실행할 때는 파이썬 환경을 내려받느라 10~20초 걸리니 기다려 주세요. 코드를 마음대로 고쳐 다시 실행해도 괜찮습니다. 망가뜨려도 새로 고침하면 원래대로 돌아옵니다.

  • print(...): 괄호 안의 내용을 화면에 보여 줍니다.
  • # 뒤의 글은 주석입니다. 사람을 위한 메모라서 실행되지 않습니다.
  • 이름 = 값: 값에 이름표를 붙여 저장합니다. 이 이름을 변수라고 합니다. =는 ‘같다’가 아니라 ‘저장하라’는 뜻입니다.
계산 기호 더하기 +, 빼기 -, 곱하기 *, 나누기 /, 거듭제곱 **, 반올림 round(값, 자릿수)

2리스트: 여러 값을 한 번에 공통

값이 여러 개일 때는 대괄호 [ ] 안에 쉼표로 나열한 리스트에 담습니다. 리스트의 자리 번호(인덱스)는 1이 아니라 0부터 시작한다는 점을 꼭 기억하세요.

평균은 (72 + 85 + 64 + 90 + 78) ÷ 5 = 389 ÷ 5 = 77.8점입니다. 손 계산과 파이썬의 결과가 같은지 확인해 보세요.

3pandas와 DataFrame: 표 데이터 다루기 공통

데이터 분석에서는 행과 열로 된 표를 다룹니다. 파이썬에서 표를 다루는 대표 도구가 pandas이고, pandas의 표를 DataFrame(데이터프레임)이라고 부릅니다. 각 열은 하나의 속성, 각 행은 하나의 레코드(학생 한 명)입니다. 맨 왼쪽의 0, 1, 2… 는 행 번호표인 인덱스입니다.

코드하는 일
import pandas as pdpandas를 불러와 pd라는 짧은 이름으로 쓴다. (맨 처음 한 번)
df = load_csv("study.csv")교재 데이터 파일을 읽어 DataFrame으로 만든다. (보통은 pd.read_csv("파일 경로"))
df.head()맨 앞 5행을 보여 준다. df.head(10)은 10행.
df.shape(행 수, 열 수)를 알려 준다. 괄호 없이 쓴다.
df.info()열 이름, 결측이 아닌 값의 수, 자료형을 한 번에 보여 준다.
df.describe()숫자 열마다 개수·평균·표준편차·최솟값·사분위수·최댓값을 요약한다.

결과를 보면 study.csv는 120행 × 6열이고 결측이 없습니다. ‘학생’ 열은 글자(object), ‘결석일수’와 ‘성적’은 정수(int64), 나머지는 소수(float64)입니다. describe()에서 성적의 평균은 약 64.7점, 가장 낮은 점수는 40점, 가장 높은 점수는 99점임을 알 수 있습니다.

4열 선택·조건 필터·정렬 공통

이제 표에서 원하는 부분만 골라 봅시다. 세 가지 기본 동작만 알면 대부분의 질문에 답할 수 있습니다.

동작코드 예뜻
열 선택df["성적"]
df[["학생", "성적"]]		한 열은 대괄호 한 겹, 여러 열은 대괄호 두 겹(열 이름 리스트)
조건 필터df[df["공부시간"] >= 4]조건이 참인 행만 남긴다. 같다는 ==(등호 두 개)
정렬df.sort_values("성적", ascending=False)성적 순으로 줄 세우기. ascending=False는 큰 값부터(내림차순)
DataFrame 조작 미리보기 — 버튼으로 고르면 코드와 결과가 바로 보여요

study.csv의 앞 12행을 mini = df.head(12)로 가져온 작은 표입니다. 조건·정렬·열·행 수를 바꾸면 그에 맞는 pandas 코드가 만들어지고 결과 표가 바뀝니다. 코드는 필터 → 정렬 → 열 선택 → 앞에서 n행 순서로 이어 붙습니다.

    하루 4시간 이상 공부하는 학생은 120명 중 7명이고 이들의 평균 성적은 86.1점으로, 전체 평균(64.7점)보다 20점 넘게 높습니다.
생각 열기의 질문에 코드 몇 줄로 답한 셈입니다. 다만 7명은 적은 수이므로 ‘공부를 4시간 넘게 하면 반드시 86점’처럼 일반화해서는 안 됩니다.
    


    
  자주 만나는 오류와 해결법
  
      
    
    • NameError: name 'df' is not defined — 위쪽 셀(③)을 먼저 실행하지 않았습니다. 셀은 위에서부터 차례로 실행하세요.
      • 
    
    • KeyError: '성적 ' — 열 이름 오타(띄어쓰기 포함). df.columns로 정확한 이름을 확인하세요.
      • 
    
    • SyntaxError — 따옴표·괄호 짝이 맞지 않거나, 같다를 = 하나로 썼습니다. 비교는 ==입니다.
      • 
    
    • 두 조건을 and로 이으면 오류가 납니다. pandas에서는 &(그리고), |(또는)를 쓰고 각 조건을 괄호로 감쌉니다.

  지도 팁
  첫 pandas 수업이므로 속도보다 ‘실행 → 결과 읽기 → 한 군데 고쳐 다시 실행’의 리듬을 익히는 데 집중하세요(셀 ①② 10분, ③ 12분, 위젯 8분, ④·활동 15분).
  위젯은 코드를 직접 치기 전 ‘코드와 결과의 대응’을 눈으로 익히는 용도입니다. 위젯에서 만든 코드를 셀 ④에 옮겨 적고 mini를 df로 바꾸어 실행하게 하면 자연스럽게 넘어갑니다.
  흔한 오개념: 인덱스가 1부터 시작한다, =와 ==를 같은 것으로 생각한다. 스프레드시트의 ‘필터’·‘정렬’ 메뉴와 나란히 비교해 보여 주면 이해가 빠릅니다.
