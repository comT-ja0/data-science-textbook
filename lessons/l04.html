1데이터의 세 가지 형태 공통

데이터는 구조(정해진 틀)가 얼마나 갖춰져 있는가에 따라 세 가지로 나눕니다.

형태특징예
정형 데이터행과 열로 이루어진 표에 미리 정한 형식대로 저장된 데이터. 열마다 값의 종류(숫자·날짜 등)가 정해져 있어 바로 계산·검색·정렬할 수 있다.성적표, 식단표, 교통카드 승하차 기록, CSV 파일, 데이터베이스 테이블
반정형 데이터표처럼 고정된 틀은 아니지만 태그나 이름(키)으로 구조를 표시한 데이터. 데이터 안에 구조 정보가 함께 들어 있다.JSON, XML, HTML 문서, 공공데이터 API 응답
비정형 데이터정해진 구조가 없는 데이터. 그대로는 계산하기 어려워 분석하려면 특징을 뽑아내는 처리가 필요하다.사진, 동영상, 음성, SNS 글, 손글씨, 뉴스 기사

오늘날 만들어지는 데이터의 대부분은 사진·영상·글 같은 비정형 데이터라고 알려져 있습니다. 그래서 비정형 데이터를 분석 가능한 형태로 바꾸는 기술(이미지 인식, 음성 인식, 자연어 처리 등)이 데이터 과학에서 점점 더 중요해지고 있습니다.

3반정형 데이터: JSON과 XML 삼양

인터넷에서 프로그램끼리 데이터를 주고받을 때는 주로 반정형 형식을 씁니다. 같은 급식 정보를 두 형식으로 나타내 보겠습니다.

JSON (JavaScript Object Notation)

{
  "날짜": "2025-03-03",
  "칼로리": 812,
  "메뉴": ["쌀밥", "미역국",
           "제육볶음", "배추김치"]
}

XML (eXtensible Markup Language)

<급식>
  <날짜>2025-03-03</날짜>
  <칼로리>812</칼로리>
  <메뉴>쌀밥</메뉴>
  <메뉴>미역국</메뉴>
  <메뉴>제육볶음</메뉴>
  <메뉴>배추김치</메뉴>
</급식>
  • JSON은 "이름": 값 쌍으로 구조를 표시합니다. 값으로 목록([ ])이나 또 다른 묶음({ })을 넣을 수 있어 날마다 메뉴 개수가 달라도 담을 수 있습니다.
  • XML은 <태그>값</태그>처럼 여는 태그와 닫는 태그로 값을 감쌉니다. 웹 페이지를 만드는 HTML도 같은 방식입니다.
  • 표(정형)라면 ‘메뉴1, 메뉴2, …’ 칸을 미리 몇 개 만들어야 하지만, 반정형은 구조가 유연합니다. 대신 분석하려면 규칙에 따라 읽어서 표로 바꾸는 과정이 필요합니다.

공공데이터포털 같은 곳에서 제공하는 오픈 API도 대부분 JSON이나 XML로 결과를 보내 줍니다. 파이썬으로 JSON을 표로 바꾸어 봅시다.

5일 치 JSON이 한 줄에 메뉴 하나씩, 모두 21행의 표가 되었습니다. 이제 “가장 자주 나온 메뉴는 배추김치(3회)”처럼 바로 셀 수 있습니다. 이처럼 반정형 데이터는 구조가 표시되어 있으므로 규칙대로 읽어 정형 데이터로 바꿀 수 있습니다.

4비정형 데이터에서 가치 꺼내기 씨마스 천재

급식 사진을 표로

식판 사진 한 장은 그대로는 계산할 수 없는 비정형 데이터입니다. 하지만 사진을 보고 어떤 반찬이 있었는지 0과 1로 기록하면 정형 데이터가 됩니다. 요즘은 사람이 직접 하지 않아도 이미지 인식 인공지능이 사진 속 음식을 찾아 표를 채워 주기도 합니다.

사진 속에 숨은 정형 데이터: 메타데이터

스마트폰으로 찍은 사진 파일에는 이미지 말고도 촬영 날짜·시각, 위치(위도·경도), 카메라 기종, 해상도 같은 정보가 ‘이름: 값’ 형태로 함께 저장됩니다. 이렇게 데이터에 대한 데이터를 메타데이터(metadata)라고 합니다. 사진 1,000장의 메타데이터를 모으면 “어느 계절·장소에서 사진을 많이 찍었는지”를 표로 분석할 수 있습니다. 반대로 위치 정보가 담긴 사진을 그대로 인터넷에 올리면 집이나 학교 위치가 드러날 수 있으므로, 공유 전에 위치 정보를 지우는 습관이 필요합니다.

글을 표로: 단어 세기

급식 만족도 게시판의 자유로운 후기(비정형 텍스트)도 특정 단어가 몇 번 나오는지 세면 표가 됩니다.

후기 8개 중 5개(약 62%)에 ‘맛있’이 들어 있고, ‘짜요’는 2개입니다. 문장 그대로는 비교할 수 없던 의견이 숫자로 바뀌었습니다. 다만 “맛있지 않아요”처럼 부정 표현이 섞이면 단순 세기는 틀릴 수 있어서, 실제 분석에서는 더 정교한 자연어 처리 방법을 사용합니다.

지도 팁 흔한 오개념: “숫자면 정형, 글자면 비정형”. 글자로 된 성명·반 이름도 표의 칸에 들어 있으면 정형 데이터이고, 숫자로 된 센서 값도 JSON으로 오면 반정형입니다. 형태는 내용이 아니라 구조로 판단한다는 점을 강조하세요. 또한 HTML·이메일처럼 구조 부분과 자유로운 본문이 섞인 데이터는 교재마다 분류가 조금 다를 수 있으니, 정답보다 판단 근거를 말하게 하는 것이 좋습니다. 코딩이 부담스러운 학급은 공공데이터포털에서 같은 데이터의 CSV와 JSON 파일을 내려받아 메모장으로 열어 비교하는 활동으로 대신할 수 있습니다.

📌 핵심 정리

  • 정형 데이터는 행과 열의 표로 된 데이터, 반정형 데이터는 태그·키로 구조를 표시한 데이터(JSON·XML·HTML), 비정형 데이터는 정해진 구조가 없는 데이터(사진·영상·음성·글)이다.
  • 데이터 형태는 내용(숫자/글자)이 아니라 구조로 판단한다.
  • 반정형 데이터는 규칙대로 읽어 표로 바꿀 수 있고, 비정형 데이터는 0/1 기록, 단어 세기, 메타데이터 추출 등으로 특징을 뽑아 정형화한다.
  • 사진 메타데이터처럼 숨은 데이터에는 가치와 함께 개인정보 위험도 있다.
