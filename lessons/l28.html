1회귀란 무엇인가 공통

‘회귀(regression)’라는 말은 영국의 과학자 프랜시스 골턴에게서 나왔습니다. 골턴은 1886년 발표한 연구에서 부모와 자녀의 키를 비교하다가, 부모의 키가 아주 큰 경우 자녀는 대체로 부모보다는 작고, 부모의 키가 아주 작은 경우 자녀는 대체로 부모보다는 크다는 것을 발견했습니다. 자녀의 키가 전체 평균 쪽으로 되돌아가는(회귀하는) 경향이 있다는 뜻에서 ‘평균으로의 회귀’라고 불렀고, 이때 두 변수의 관계를 직선으로 나타낸 방법이 오늘날 회귀 분석의 이름이 되었습니다.

오늘날 회귀 분석은 독립 변수 x로 종속 변수 y를 설명·예측하는 식을 찾는 방법을 말합니다. 독립 변수가 하나이고 관계를 직선으로 나타내면 단순 선형 회귀입니다.

ŷ = a·x + b ŷ(와이 햇)은 예측값, a는 기울기(회귀 계수), b는 절편입니다. 실제값 y와 예측값 ŷ의 차이 y − ŷ를 잔차(오차)라고 합니다.

4결정계수 R²: 평균보다 얼마나 나아졌나 천재

회귀식을 찾았다면 “이 직선이 데이터를 얼마나 잘 설명하는가?”를 물어야 합니다. 기준은 아무 정보도 쓰지 않는 평균선입니다. 공부시간을 모른다면 모든 학생의 성적을 평균 70점으로 예측할 수밖에 없고, 이때의 오차 제곱합을 총제곱합(SST)이라고 합니다.

  • 평균선의 오차 제곱합 SST = 15² + 10² + 0² + 5² + 20² = 225 + 100 + 0 + 25 + 400 = 750
  • 회귀선의 오차 제곱합 SSE = 27.5
R² = 1 − SSE ÷ SST = 1 − 27.5 ÷ 750 ≈ 0.963 위 게임에서 ‘평균선의 오차 제곱 보기’를 켜면 회색 사각형(SST)과 주황 사각형(SSE)의 넓이를 비교할 수 있습니다.

결정계수 R²는 평균선의 오차(사각형 넓이) 중에서 회귀선이 줄여 준 비율입니다. R² = 0.963은 “성적의 흩어짐 중 약 96.3%를 공부시간과의 직선 관계로 설명한다”는 뜻입니다. R²는 0에 가까울수록 평균선보다 나을 게 없고, 1에 가까울수록 점들이 직선에 가깝게 모여 있습니다. 단순 선형 회귀에서는 R²가 상관계수 r의 제곱과 같습니다(이 예에서 r ≈ 0.9815, r² ≈ 0.963).

R²는 ‘정확도’가 아니다 R² = 0.96을 “96% 정확하다”고 읽으면 안 됩니다. R²는 평균선과 비교해 오차가 얼마나 줄었는지를 나타내는 비율입니다. 또한 R²가 높아도 인과관계를 뜻하지 않으며, 데이터 범위 밖(예: 공부시간 20시간)의 예측까지 보장하지 않습니다.

5파이썬으로 통계적 회귀: 계수와 p값 해석 YBM 씨마스

먼저 손계산 결과를 코드로 확인하고, 이어서 study.csv(학생 120명)로 실제 분석을 해 봅시다.

통계적 회귀는 회귀식을 구하는 데서 끝나지 않고, “이 기울기가 우연히 나온 것은 아닌가?”를 따집니다. 이때 쓰는 값이 p값입니다. p값은 “만약 x와 y가 사실은 아무 관계가 없다면(진짜 기울기가 0이라면), 지금 데이터에서 얻은 정도로 큰 기울기가 우연히 나올 확률”입니다. 보통 p값이 0.05보다 작으면 우연으로 보기 어렵다고 판단하여 “통계적으로 유의하다”고 말합니다.

실행 결과를 해석해 봅시다.

  • 공부시간 → 성적: 기울기 7.739, 절편 47.870, R² 0.569, p값은 약 2.45 × 10−23으로 0.05보다 훨씬 작습니다. “공부시간이 1시간 많은 학생은 성적이 평균적으로 약 7.7점 높은 경향이 있고, 이 관계는 우연으로 보기 어렵다.” 공부시간이 성적의 흩어짐 중 약 57%를 설명합니다. 절편 47.87은 공부시간 0시간일 때의 예측값이지만, 데이터의 공부시간은 0.4시간부터라 해석에 주의해야 합니다.
  • 결석일수 → 성적: 기울기 −0.655, R² 0.005, p값 0.443으로 0.05보다 큽니다. 기울기가 음수이기는 하지만 우연으로도 충분히 나올 수 있는 크기이므로 결석일수가 성적을 설명한다고 말하기 어렵습니다.
  • 성적을 무작위로 섞으면 기울기가 0 가까이로 떨어지고 p값이 커집니다. 1000번 섞어도 기울기가 실제 값 7.74 근처에 가지 못합니다. p값이 아주 작다는 것은 바로 이런 뜻입니다.
통계적 회귀의 관점 통계적 회귀는 데이터 전체로 식을 구하고, 계수의 의미와 p값·R²를 따져 “x가 y를 설명하는가, 얼마나 설명하는가”에 답하는 데 초점을 둡니다. 다음 차시에서는 같은 문제를 기계학습의 관점—훈련 데이터로 학습하고 처음 보는 데이터로 예측 성능을 평가—으로 풀어 봅니다. (참고: Python의 statsmodels 라이브러리를 쓰면 OLS 결과 표로 계수·p값·R²를 한꺼번에 볼 수 있습니다. 이 교재의 셀에서는 같은 값을 주는 scipy.stats.linregress를 사용합니다.)

정답 확인
x̄ = 2.5, ȳ = 5. x − x̄ = −1.5, −0.5, 0.5, 1.5 / y − ȳ = −3, 0, 1, 2. Σ(x − x̄)(y − ȳ) = 4.5 + 0 + 0.5 + 3 = 8, Σ(x − x̄)² = 2.25 + 0.25 + 0.25 + 2.25 = 5. a = 8 ÷ 5 = 1.6, b = 5 − 1.6 × 2.5 = 1 → ŷ = 1.6x + 1.
예측값 2.6, 4.2, 5.8, 7.4 → 오차 −0.6, 0.8, 0.2, −0.4 → SSE = 0.36 + 0.64 + 0.04 + 0.16 = 1.2. SST = 9 + 0 + 1 + 4 = 14 → R² = 1 − 1.2 ÷ 14 ≈ 0.914.
500쪽(x = 5) → 1.6 × 5 + 1 = 9시간. 다만 데이터가 4명뿐이고 400쪽까지만 있어서 500쪽은 범위 밖 예측(외삽)이므로 조심해야 합니다.
지도 팁 손계산 → 게임 → 코드 순서가 효과적입니다. 게임에서 학생들이 SSE 27.5에 도달하면 ‘최소제곱 해 보기’로 확인하게 하고, 이어서 점 하나를 멀리 끌어 이상치가 회귀선을 얼마나 끌어당기는지 관찰시키세요(제곱 때문에 큰 오차에 민감함). 스프레드시트를 쓰는 학급은 SLOPE·INTERCEPT·RSQ 함수로 같은 값을 확인할 수 있고, 구글 시트의 LINEST 함수는 표준오차까지 보여 줍니다. p값은 ‘관계가 없다고 가정했을 때 이런 결과가 나올 확률’이라는 뜻만 다루고, 가설 검정의 형식적 절차는 깊이 들어가지 않아도 됩니다. “p값이 작다 = 효과가 크다”는 흔한 오개념이므로 기울기(효과의 크기)와 p값(우연 가능성)을 구분시키세요.

📌 핵심 정리

  • 회귀 분석은 독립 변수로 종속 변수를 설명·예측하는 식을 찾는 방법이며, 이름은 골턴의 ‘평균으로의 회귀’에서 왔다.
  • 최소제곱법은 오차 제곱합(SSE)이 가장 작은 직선을 공식 a = Σ(x−x̄)(y−ȳ)/Σ(x−x̄)², b = ȳ − a·x̄로 한 번에 구한다.
  • R² = 1 − SSE/SST는 평균선의 오차를 회귀선이 줄인 비율이다(정확도가 아님).
  • 회귀 계수는 x가 1 늘 때 y의 평균적 변화량이고, p값이 0.05보다 작으면 그 관계가 우연으로 보기 어렵다고 판단한다.
