1기계학습에서 ‘학습’이란 공통

기계학습 회귀 모델도 ŷ = w·x + b 꼴의 식을 씁니다. 기계학습에서는 기울기를 가중치(weight) w, 절편을 편향(bias) b이라고 부르는 경우가 많습니다. 처음에는 w와 b를 아무 값(예: 0)으로 두고, 예측이 얼마나 틀렸는지를 재어 조금씩 고쳐 나갑니다. 이 과정이 학습(훈련)입니다.

“얼마나 틀렸는지”를 하나의 숫자로 재는 식을 손실 함수(loss function)라고 합니다. 회귀에서는 주로 평균 제곱 오차(MSE)를 씁니다.

MSE = (1/n) × Σ(y − ŷ)² 오차 제곱합(SSE)을 데이터 개수 n으로 나눈 값입니다. MSE를 가장 작게 하는 w, b는 SSE를 가장 작게 하는 w, b와 같습니다. 곧 최소제곱법과 목표가 같습니다.
통계적 회귀(최소제곱 공식)기계학습 회귀(경사 하강법)

목표오차 제곱의 합(평균)을 가장 작게 — 같은 답에 도착
장점정확하고 빠름(선형 회귀처럼 공식이 있을 때)공식이 없는 복잡한 모델(신경망 등)에도 쓸 수 있음

2경사 하강법과 학습률 공통

경사 하강법(gradient descent)은 손실 함수의 기울기(경사)를 계산해 손실이 줄어드는 반대 방향으로 매개변수를 조금 옮기는 일을 반복하는 방법입니다. 한 번에 얼마나 옮길지를 정하는 값이 학습률(learning rate)입니다.

w ← w − 학습률 × (∂MSE/∂w)　　b ← b − 학습률 × (∂MSE/∂b) ∂MSE/∂w = −(2/n)·Σ x(y − ŷ),　∂MSE/∂b = −(2/n)·Σ (y − ŷ). 기울기가 음수(내리막이 오른쪽)면 w를 키우고, 양수면 w를 줄입니다.

한 걸음 손으로 계산해 보기

지난 차시의 5명 데이터(공부시간 1~5시간, 성적 55·60·70·75·90점)로 w = 0, b = 0, 학습률 0.01에서 시작합니다.

  • 처음 예측은 모두 0점이므로 오차는 55, 60, 70, 75, 90. MSE = (55² + 60² + 70² + 75² + 90²) ÷ 5 = 25250 ÷ 5 = 5050
  • ∂MSE/∂w = −(2/5) × (1×55 + 2×60 + 3×70 + 4×75 + 5×90) = −(2/5) × 1135 = −454
  • ∂MSE/∂b = −(2/5) × (55 + 60 + 70 + 75 + 90) = −(2/5) × 350 = −140
  • 새 w = 0 − 0.01 × (−454) = 4.54, 새 b = 0 − 0.01 × (−140) = 1.4 → MSE는 약 3059.7로 줄어듭니다.

이 걸음을 계속 반복하면 w와 b는 지난 차시에 공식으로 구한 8.5와 44.5에 점점 가까워집니다. 아래 실행기로 직접 확인해 보세요.

학습률이 너무 작으면

한 걸음이 너무 짧아 바닥까지 아주 오래 걸린다. 정해진 반복 횟수 안에 도착하지 못할 수 있다.

학습률이 적당하면

손실이 빠르게 줄어들다 바닥 근처에서 안정된다. 최소제곱 해와 같은 답에 도착한다.

학습률이 너무 크면

바닥을 지나쳐 반대편으로 튀어 오르며 손실이 오히려 커진다. 계속되면 값이 폭발하는 발산이 일어난다.

3훈련 데이터와 테스트 데이터 공통

기계학습의 목적은 이미 본 데이터를 잘 맞히는 것이 아니라, 처음 보는 데이터를 잘 예측하는 것입니다. 시험 문제를 미리 보고 공부하면 점수가 높아도 실력을 알 수 없듯이, 모델을 학습시킨 데이터로 채점하면 성능을 믿을 수 없습니다. 그래서 데이터를 둘로 나눕니다.

훈련 데이터 80% — 모델 학습(w, b 찾기)
테스트 20%
  • 훈련 데이터: 경사 하강법으로 w, b를 찾는 데 쓴다.
  • 테스트 데이터: 학습이 끝날 때까지 절대 보여 주지 않았다가 마지막에 예측 성능을 평가하는 데만 쓴다.
  • 무작위로 나누되 random_state(난수 씨앗)를 고정하면 누가 실행해도 같은 방식으로 나뉘어 결과를 다시 확인(재현)할 수 있다.
데이터 누수 주의 평균·표준편차로 표준화할 때도 훈련 데이터로만 평균과 표준편차를 구해야 합니다. 테스트 데이터의 정보가 학습에 섞여 들어가면(데이터 누수) 성능이 실제보다 좋게 나옵니다.

4파이썬 실습: 기온으로 자전거 대여량 예측하기 공통 삼양

bike.csv의 기온(x)으로 대여량(y)을 예측하는 회귀 모델을 ① 경사 하강법을 numpy로 직접 구현해서, ② scikit-learn으로 만들어 비교합니다.

기온은 −8℃부터 34℃까지 범위가 넓어서 그대로 경사 하강법을 쓰면 학습률을 아주 작게 해야 하고 반복도 많이 필요합니다. 그래서 기온을 표준화(평균 0, 표준편차 1)한 뒤 학습하고, 끝나면 원래 단위의 기울기·절편으로 되돌립니다.

이번에는 scikit-learn의 LinearRegression으로 같은 훈련 데이터를 학습합니다. LinearRegression은 경사 하강법처럼 반복하지 않고 최소제곱 해를 행렬 계산으로 바로 구합니다. 반면 SGDRegressor는 경사 하강법(데이터를 조금씩 나누어 쓰는 확률적 경사 하강법)으로 반복 학습하는 모델입니다.

실행 결과를 정리해 봅시다. 직접 구현한 경사 하강법은 약 50번 반복하자 훈련 MSE가 더 줄어들지 않는 바닥(약 912210)에 도착했고, 최종 식 대여량 = 50.972 × 기온 + 2848.372는 LinearRegression이 한 번에 계산한 답과 소수점 셋째 자리까지 같습니다. SGDRegressor도 거의 같은 값(약 51.1, 2846.5)을 찾았습니다. 세 방법은 계산하는 길만 다를 뿐, MSE를 가장 작게 하는 같은 답에 도착합니다. 기울기 약 51은 “기온이 1℃ 높은 날 대여량이 평균 약 51대 많은 경향”을 뜻합니다. 처음 보는 테스트 73일에 대해서는 RMSE 약 798대, R² 0.435였습니다. 예측이 평균적으로 800대 가까이 빗나가고, 대여량 흩어짐의 절반도 설명하지 못한다는 뜻입니다. 산점도를 보면 기온이 아주 높은 날 대여량이 다시 줄어드는 곡선 관계가 보이므로, 다음 차시들에서 변수를 늘리거나 다른 모델을 써서 개선해 봅니다.

📌 핵심 정리

  • 기계학습의 학습은 손실 함수(회귀에서는 주로 MSE)가 작아지도록 가중치 w와 편향 b를 반복해서 고치는 과정이다.
  • 경사 하강법은 손실의 기울기 반대 방향으로 학습률만큼 이동한다. 학습률이 너무 작으면 느리고, 너무 크면 발산한다.
  • LinearRegression은 최소제곱 해를 바로 계산하고, 경사 하강법(SGDRegressor 등)은 반복으로 같은 답에 다가간다.
  • 모델은 훈련 데이터로 학습하고, 한 번도 보지 않은 테스트 데이터로 평가한다. random_state로 분할을 재현할 수 있게 한다.
