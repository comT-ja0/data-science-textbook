성취기준 12데과01-01~04
🎯 학습 목표
  • 생활 속 상식을 데이터로 확인할 수 있는 질문으로 바꾸고, 데이터를 근거로 참·거짓을 판단할 수 있다.
  • 데이터 기반 의사 결정 사례를 문제·데이터·분석·결정의 흐름으로 분석해 보고서를 쓸 수 있다.
  • Ⅰ영역에서 배운 데이터의 형태·속성·통합·사회 변화 개념을 프로젝트에 적용할 수 있다.
[12데과01-01] 데이터 과학의 개념을 이해하고, 문제 해결 사례를 데이터 기반 의사 결정 상황에 적용한다. [12데과01-02] 정형 데이터와 비정형 데이터를 구분하고, 데이터 속성에서 데이터의 잠재적 가치를 파악한다. [12데과01-03] 데이터셋의 집합인 데이터베이스를 이해하고, 서로 다른 데이터셋의 데이터를 분석이 가능한 형태로 통합하는 것의 의미를 파악한다. [12데과01-04] 데이터로 인한 사회 변화를 인식하고, 진로 및 직업과 관련한 데이터 기반 문제 해결 사례를 분석한다.
문제 정의수집전처리탐색모델링평가·해석공유
생각 열기 “요즘 여름은 옛날보다 훨씬 덥다니까.” 할머니 말씀에 삼촌이 반박합니다. “그건 기분 탓이에요. 옛날에도 더웠어요.” 둘 중 누구 말이 맞을까요? 목소리가 큰 사람이 이기는 말싸움 대신, 데이터를 펼쳐 보면 결론을 낼 수 있습니다. 오늘은 우리가 ‘당연히 맞다’고 믿는 상식을 데이터로 검증하고, 데이터로 결정을 내린 실제 사례를 분석하는 미니 프로젝트를 합니다.

1프로젝트 안내: 상식을 데이터로 검증하기 씨마스

상식 검증 프로젝트는 데이터 과학의 문제 해결 과정을 작게 한 바퀴 돌아 보는 활동입니다. 다음 다섯 단계로 진행합니다.

단계할 일예시
① 상식 고르기주변에서 흔히 듣는 말 중 데이터로 확인할 수 있는 것을 고른다.“요즘 여름이 더 덥다.”
② 질문으로 바꾸기무엇을, 언제와 언제를, 어떤 값으로 비교할지 측정 가능한 질문으로 바꾼다.“최근 10년의 연평균기온은 50년 전 10년보다 높은가?”
③ 데이터 찾기질문에 답할 수 있는 데이터를 찾고 출처·기간·속성을 기록한다.climate.csv (연도, 연평균기온, 폭염일수)
④ 분석·판단평균 비교, 그래프 등으로 확인하고 O/X를 판단한다.두 기간 평균 비교, 연도별 선 그래프
⑤ 한계·공유데이터의 한계(기간·지역·표본)를 밝히고 결과를 발표한다.“한 지역 자료이므로 전국으로 일반화하려면…”
측정 가능한 질문 만들기 “요즘 청소년은 책을 안 읽는다”처럼 모호한 말은 그대로 검증할 수 없습니다. 누구(고등학생), 무엇(한 달 독서 권수), 비교 기준(10년 전과 비교)을 정해야 데이터로 답할 수 있는 질문이 됩니다.

2상식 O/X 검증기 씨마스

상식 O/X 검증기 — 먼저 예측하고, 데이터로 확인하기

상식 카드를 고르고 O 또는 X를 먼저 예측하세요. 예측하면 교재 데이터로 계산한 그래프와 판정이 나타납니다. (교재 데이터는 수업용 가상 데이터입니다. 실제 통계로 검증하려면 공공 데이터를 찾아야 합니다.)

예측한 카드 0/6 내 상식 적중 0개

생각해 보기: 예측이 틀린 카드는 왜 그런 상식이 생겼을까요? 그리고 그래프의 세로축이 0에서 시작하는지도 꼭 확인하세요.

3파이썬으로 상식 검증하기 공통

생각 열기의 질문 “요즘 여름이 더 덥다”를 climate.csv로 직접 검증해 봅시다. 이 데이터는 한 지역의 1975~2025년 연평균기온과 폭염일수(하루 최고기온이 33℃ 이상인 날의 수)를 담고 있습니다.

두 기간의 평균을 비교하면 최근 10년이 약 1.3℃ 높고, 폭염일수도 평균 7.5일에서 18.9일로 늘었습니다. 그런데 그래프를 보면 기온이 전년보다 내려간 해도 스무 번이 넘습니다. 그래서 “작년보다 올해가 더 덥다”는 늘 맞는 말은 아니지만, “수십 년 동안 더워지는 추세가 있다”는 말은 이 데이터로 뒷받침됩니다. 한 해 한 해의 들쭉날쭉함과 긴 흐름을 구분하는 것이 데이터를 읽는 힘입니다.

4데이터 기반 의사 결정 사례 분석 보고서 삼양 씨마스

두 번째 과제는 실제 사회에서 데이터로 결정을 내린 사례를 조사해 분석하는 것입니다. 사례를 분석할 때는 데이터 분석이 어떤 목적에 쓰였는지 네 가지로 나누어 보면 이해가 깊어집니다.

목적묻는 질문예시 (학교 매점)

5발표와 자기 평가 씨마스

모둠별로 3분 동안 상식 검증 결과 또는 사례 분석 결과를 발표합니다. 발표 뒤에는 아래 기준으로 스스로 평가하고, 다른 모둠에게 질문을 하나씩 해 봅시다.

평가 기준잘함보통노력
상식을 측정 가능한 질문으로 바꾸었다.□□□
데이터의 출처·기간·속성을 밝혔다.□□□
수치나 그래프를 근거로 판정했다.□□□
데이터의 한계와 일반화의 주의점을 설명했다.□□□
모둠원과 역할을 나누어 협력했다.□□□
지도 팁 이 차시는 확장 차시로, 1차시(50분)에 운영할 때는 상식 검증(검증기 10분 + 파이썬 또는 스프레드시트 20분 + 발표 15분)에 집중하고 사례 분석 보고서는 과제로 돌립니다. 2차시로 늘릴 수 있으면 Gapminder Tools(무료 웹 도구)로 ‘세계의 기대 수명·소득’ 같은 상식을 검증하는 활동을 추가해도 좋습니다. 학생들이 교재 가상 데이터의 결과를 실제 사실로 받아들이지 않도록, 결론 문장에 “이 데이터에서는”을 붙이는 습관을 지도하세요.

📌 핵심 정리

  • 상식을 검증하려면 누구·무엇·비교 기준을 정해 측정 가능한 질문으로 바꾸어야 한다.
  • 한 해·한 번의 값과 긴 기간의 추세를 구분하고, 그래프의 축과 데이터의 한계를 함께 확인한다.
  • 데이터 기반 의사 결정 사례는 문제–데이터–분석(설명·진단·예측·처방)–결정–영향의 흐름으로 분석한다.
