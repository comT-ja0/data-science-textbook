2같은 분석, 세 가지 도구 씨마스

도구가 달라도 계산 원리가 같으면 결과도 같습니다. 학생 5명의 공부시간(시간)과 성적(점) 데이터로 확인해 봅시다.

학생공부시간 (B열)성적 (C열)

📊 스프레드시트

셀에 함수를 입력한다.

=AVERAGE(C2:C6)     → 70
=CORREL(B2:B6,C2:C6) → 0.98
=SLOPE(C2:C6,B2:B6)  → 8.5
=INTERCEPT(C2:C6,B2:B6) → 44.5

⌨️ Python

코드 몇 줄로 계산한다.

df["성적"].mean()    # 70.0
df["공부시간"].corr(df["성적"])
np.polyfit(df["공부시간"],
           df["성적"], 1)
# [ 8.5  44.5]

세 도구 모두 평균 70점, 상관계수 약 0.98, 추세선 성적 = 8.5 × 공부시간 + 44.5를 얻습니다. 결과가 같다면 무엇이 다를까요? 작업이 기록되는 방식입니다. 스프레드시트는 결과가 셀에 흩어져 남고, Orange는 작업 흐름이 그림(위젯 연결)으로 남고, Python은 작업 전체가 코드(글)로 남습니다. 코드와 위젯 흐름은 다른 데이터에 그대로 다시 적용하거나 친구에게 공유하기 쉽습니다.

3Orange의 위젯 파이프라인 천재 씨마스

Orange는 각 기능이 위젯(작은 상자)으로 되어 있고, 위젯과 위젯을 선으로 이어 데이터가 흘러가는 길, 곧 파이프라인을 만듭니다. 왼쪽에서 오른쪽으로 데이터가 흐르며, 앞 위젯의 결과가 뒤 위젯의 입력이 됩니다.

Orange의 한계를 알고 쓰기 Orange의 Linear Regression 위젯은 회귀 계수(기울기·절편)는 보여 주지만, 그 계수가 통계적으로 의미 있는지 알려 주는 p값 같은 검정 결과는 제공하지 않습니다. 통계적 회귀를 제대로 해석하려면 Python의 scipy·statsmodels나 R을 함께 씁니다. 다음 차시(L28)에서 Python으로 p값을 직접 구해 봅니다.

5파이썬: 반복문 대신 한 줄로 공통

프로그래밍 도구의 힘은 라이브러리에서 나옵니다. 평균 하나를 구할 때도 반복문을 직접 짜는 방법과 pandas 함수 한 줄로 끝내는 방법이 있습니다. 결과가 같은지, 코드 길이와 실행 속도는 어떻게 다른지 비교해 보세요.

두 방법의 결과는 같지만 pandas가 훨씬 짧고, 데이터가 커질수록 속도 차이가 수십 배 이상 벌어집니다(실행하는 컴퓨터마다 시간은 조금씩 다릅니다). 참고로 스프레드시트 한 시트에 넣을 수 있는 행 수에는 한계가 있어(엑셀은 약 100만 행) 대용량 데이터에는 프로그래밍 도구가 알맞습니다.

지도 팁 이 차시는 ‘어느 도구가 최고인가’가 아니라 상황에 따라 고르는 기준을 세우는 것이 목표입니다. 컴퓨터실 환경이 허락하면 2절 데이터를 모둠별로 서로 다른 도구(구글 시트·CODAP·Orange·Python 셀)에 나누어 맡기고 결과를 칠판에 모아 같은지 확인하면 효과적입니다. Orange 설치가 어려운 학교는 CODAP(웹)으로 대체할 수 있습니다. 흔한 오개념은 “코딩 도구가 더 정확하다”입니다. 계산 원리가 같으면 결과는 같고, 차이는 규모·재현성·표현력에 있다는 점을 강조하세요.

📌 핵심 정리

  • 분석 도구는 스프레드시트, 위젯·블록형(Orange·CODAP), 프로그래밍 언어(Python·R)로 나눌 수 있다.
  • 계산 원리가 같으면 도구가 달라도 결과는 같다. 차이는 사용 난이도·데이터 규모·재현(반복)·가능한 분석의 범위에 있다.
  • Orange는 위젯을 연결한 파이프라인으로 분석 흐름을 그림처럼 남기고, Python은 코드로 남겨 자동화와 공유가 쉽다.
  • 도구는 데이터 크기, 사용자의 경험, 필요한 분석(기계학습·통계 검정), 환경을 고려해 고른다.
