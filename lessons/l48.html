생각 열기 지난 차시에 직선은 U자 모양의 데이터를 따라가지 못했습니다. 테스트 R²는 −0.041, 평균으로 찍은 것과 다를 바 없었죠. 그렇다면 선을 구부리면 어떨까요? 또는 선을 긋는 대신 기온을 몇 개의 구간으로 나누어 구간마다 평균을 쓰면 어떨까요? 오늘은 이 두 아이디어를 각각 모델로 만들고, 지난 차시의 선형 회귀와 같은 테스트 데이터 50일로 겨루게 합니다. 과연 점수가 가장 높은 모델이 항상 가장 좋은 모델일까요?

1곡선을 표현하는 두 가지 방법 공통

다항 회귀 (polynomial regression)

입력 x에 x²(필요하면 x³ …)을 새 속성으로 추가한 뒤 선형 회귀를 적용합니다. 2차식 y = a·x² + b·x + c는 a > 0이면 아래로 볼록한 U자 곡선이 됩니다. 식이 있어 해석하기 쉽고, 곡선이 학습 범위 밖으로도 이어집니다.

의사결정트리 회귀 (decision tree regression)

“기온 ≤ 3.3℃인가?”처럼 질문을 반복해 데이터를 구간으로 나누고, 각 구간(잎)의 평균을 예측값으로 씁니다. 분류 트리와 같은 원리이지만 잎에 범주 대신 평균이 들어갑니다. 어떤 모양의 관계든 따라가지만, 학습 범위 밖에서는 가장 끝 구간의 평균에 머뭅니다.

2방법 ②-가: 2차 다항 회귀 삼양

먼저 지난 차시와 똑같은 설계(수업일, 평균기온 → 전력사용량, 75:25 분할, random_state=42)를 다시 준비하고, 모든 모델을 같은 방식으로 평가하는 함수 report를 만듭니다.

회귀식은 전력사용량 ≈ 3.247×기온² − 99.30×기온 + 1881.4입니다. 기온²의 계수가 양수이므로 아래로 볼록한 U자 곡선이고, 꼭짓점의 기온 −(−99.30)÷(2×3.247) ≈ 15.3℃에서 사용량이 가장 적습니다. 테스트 R²는 0.723, MAE는 82.5kWh로, 선형 회귀(MAE 167.8kWh)보다 오차가 절반 이하로 줄었습니다.

3방법 ②-나: 의사결정트리 회귀 삼양 천재

트리는 깊이(질문을 몇 번 거치는가)가 깊을수록 데이터를 잘게 나눕니다. 너무 깊으면 훈련 데이터의 잡음까지 외우는 과대적합이 일어나므로, 여기서는 깊이 3(잎 최대 8개)으로 제한합니다.

트리의 규칙을 읽으면 “기온 3.3℃ 이하”와 “26.5℃ 초과”에서 크게 갈라집니다. 그 사이(6.8~26.5℃)의 날은 모두 약 1218kWh로 예측합니다. EDA에서 본 ‘평평한 바닥 + 양쪽 오르막’ 모양을 트리가 스스로 찾아낸 것입니다. 테스트 R²는 0.720, MAE는 87.0kWh입니다. 훈련 R²(0.932)가 다항 회귀(0.895)보다 높지만 테스트 성능은 비슷하거나 약간 낮습니다.

4같은 테스트 데이터로 비교하기 천재 삼양

이제 세 방법을 한 표에 모으고, 같은 그래프에 그려 비교합니다. 또 학습 데이터에 없던 날씨(−8℃ 한파, 35℃ 폭염)를 각 모델이 어떻게 예측하는지도 확인합니다.

모델 비교 실험실 — 같은 테스트 데이터 50일

모델과 설정값을 바꾸면 훈련 데이터(보라)로 학습한 곡선이 그려지고, 테스트 데이터(주황)로 평가됩니다. 마음에 드는 설정은 비교표에 추가해 한눈에 비교하세요. 회색 영역은 학습 데이터에 없던 기온입니다.

테스트 점수로 계속 고르면? 실험실에서 테스트 R²가 가장 높은 설정을 찾아 고르는 것은 사실 테스트 데이터를 학습에 쓴 것과 비슷합니다(테스트 데이터에 맞춘 선택). 그렇게 고른 모델의 테스트 점수는 실제보다 좋게 부풀려집니다. 설정값은 훈련 데이터 안에서 교차 검증으로 고르고, 테스트 데이터는 마지막에 한 번만 쓰는 것이 원칙입니다(L49).
지도 팁 Orange에서는 Polynomial Regression(Educational 애드온) 또는 Feature Constructor로 기온²를 만든 뒤 Linear Regression을, 그리고 Tree(회귀)를 같은 Test and Score에 연결하면 한 표로 비교됩니다. 12데과04-03의 핵심은 ‘두 방법을 썼다’가 아니라 ‘같은 조건에서 비교하고 목적에 따라 선택했다’입니다. 모둠 보고서에 비교표와 선택 이유가 반드시 들어가도록 지도하세요. 군집을 쓰는 모둠은 k-평균과 병합 군집을, 분류를 쓰는 모둠은 k-NN과 트리를 같은 테스트 데이터로 비교하게 안내합니다.

📌 핵심 정리

  • 곡선 관계는 다항 회귀(x² 추가 후 선형 회귀)나 의사결정트리 회귀(구간별 평균)로 표현할 수 있다.
  • 같은 테스트 데이터에서 2차 다항 회귀(R² 0.723, MAE 82.5)와 트리(R² 0.720, MAE 87.0)는 선형 회귀(MAE 167.8)보다 크게 나았다.
  • 점수가 비슷하면 목적이 선택을 결정한다: 해석 가능성, 학습 범위 밖 예측, 과대적합 위험을 함께 비교한다.
  • 테스트 데이터를 보며 설정을 계속 고르면 성능이 부풀려진다. 설정 선택은 교차 검증으로 한다.
