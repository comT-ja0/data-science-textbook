생각 열기 두 모둠이 같은 자전거 데이터를 분석해 발표했습니다. A 모둠: “우리 모델의 R²는 0.27이고, 기온의 p값은 0.001보다 작아 기온이 대여량을 설명합니다.” B 모둠: “우리 의사결정트리 모델은 R²가 0.91이나 됩니다!” 친구들은 B 모둠이 이겼다고 박수를 쳤습니다. 그런데 선생님이 물었습니다. “두 R²는 같은 데이터로 잰 것인가요?” 오늘은 회귀 모델을 공정하게 비교하고, 결과를 목적에 맞게 해석하는 법을 배웁니다.

구분통계적 회귀기계학습 회귀
주된 목적변수 사이의 관계를 설명·추론처음 보는 데이터의 값을 예측
모델의 모습주로 선형 회귀식처럼 해석하기 쉬운 식선형 회귀뿐 아니라 의사결정트리, k-NN, 신경망 등 복잡한 모델도 사용
계수 찾는 법최소제곱 공식으로 한 번에최소제곱 해 또는 경사 하강법 등으로 학습
데이터 사용주로 가진 데이터 전체로 추정훈련 데이터로 학습, 테스트 데이터로 평가
주요 결과회귀 계수, p값, R²(설명력)테스트 데이터의 MAE·RMSE·R²(예측 성능)
강점“x가 1 늘면 y가 얼마나?”를 근거와 함께 해석곡선·복잡한 관계도 유연하게 예측

주의할 점: 같은 훈련 데이터에 선형 회귀를 적용하면 통계적 방법(최소제곱 공식)이든 기계학습 방법(LinearRegression, 경사 하강법)이든 똑같은 직선이 나옵니다. 두 관점의 차이는 계산 결과보다 무엇을 묻고, 어떻게 평가하고, 어떻게 해석하느냐에 있습니다.

2회귀 모델의 평가 지표 공통

지표계산의미
MAE 평균 절대 오차|실제 − 예측|의 평균평균적으로 몇 만큼 빗나가는가. 단위가 원래 값과 같아 이해하기 쉽다.
MSE 평균 제곱 오차(실제 − 예측)²의 평균큰 오차에 더 큰 벌점. 단위가 ‘대²’처럼 제곱이라 직접 읽기 어렵다.
RMSE 평균 제곱근 오차√MSEMSE를 원래 단위로 되돌린 값. 큰 오차가 있으면 MAE보다 눈에 띄게 커진다.
R² 결정계수1 − SSE ÷ SST평균으로 예측할 때보다 오차가 얼마나 줄었는가. 1에 가까울수록 좋고, 평균보다 못하면 음수도 된다.

MAE·MSE·RMSE는 작을수록, R²는 클수록 좋은 모델입니다. 손으로 계산해 봅시다. 실제값이 3, 5, 7, 9이고 예측값이 4, 5, 5, 10이면 오차는 −1, 0, +2, −1입니다.

  • MAE = (1 + 0 + 2 + 1) ÷ 4 = 1,　MSE = (1 + 0 + 4 + 1) ÷ 4 = 1.5,　RMSE = √1.5 ≈ 1.22
  • 실제값 평균 6 → SST = 9 + 1 + 1 + 9 = 20, SSE = 6 → R² = 1 − 6 ÷ 20 = 0.7

기계학습에는 식을 직선으로 정하지 않는 회귀 모델도 있습니다. 여섯 날의 기록으로 원리를 살펴봅시다.

대여량360043004500410037003200

🌳 의사결정트리 회귀

“기온 < 24℃인가?”처럼 질문으로 구간을 나누고, 구간 안 데이터의 평균을 예측값으로 쓴다. 24℃ 미만(가~라)의 평균 (3600 + 4300 + 4500 + 4100) ÷ 4 = 4125대, 24℃ 이상(마·바)은 (3700 + 3200) ÷ 2 = 3450대. 질문을 더 하면(깊이↑) 구간이 잘게 나뉜다.

👥 k-최근접 이웃(k-NN) 회귀

예측할 날과 가장 비슷한(가까운) k개 데이터의 평균을 예측값으로 쓴다. 기온 20℃인 날을 k = 3으로 예측하면 가까운 날은 다(19℃)·라(22℃)·나(17℃) → (4500 + 4100 + 4300) ÷ 3 = 4300대.

두 모델 모두 ‘기온이 너무 높으면 대여량이 줄어드는’ 곡선 관계를 따로 식을 세우지 않고도 따라갈 수 있습니다. 대신 “기온이 1℃ 오르면 몇 대 늘어난다”처럼 한 줄로 해석하기는 어렵습니다.

4같은 테스트 데이터로 공정하게 비교하기 공통

bike.csv를 L29와 같은 방법(test_size=0.2, random_state=42)으로 나누고, 모든 모델을 같은 훈련 데이터로 학습하고 같은 테스트 데이터로 평가합니다.

테스트 73일 기준으로 선형 회귀는 MAE 639대·RMSE 798대·R² 0.435, 의사결정트리(깊이 3)는 MAE 409대·RMSE 555대·R² 0.726, k-NN(k=5)은 MAE 472대·RMSE 598대·R² 0.682입니다. 곡선 관계를 따라갈 수 있는 트리와 k-NN이 선형 회귀보다 예측을 더 잘했습니다. 또 기계학습 LinearRegression의 계수(50.97)는 통계적 회귀의 기울기와 똑같습니다.

흔한 실수: 서로 다른 데이터로 잰 점수 비교하기 ‘생각 열기’의 두 모둠처럼 한 모델은 전체 데이터(또는 훈련 데이터)의 R²를, 다른 모델은 테스트 데이터의 R²를 내놓고 비교하면 공정하지 않습니다. 훈련 데이터의 점수는 ‘이미 본 문제’의 점수라서 복잡한 모델일수록 부풀려집니다. 아래 셀에서 직접 확인해 보세요.

불공정한 비교에서는 깊이 제한 없는 트리(훈련 R² 0.908)가 선형 회귀(전체 R² 0.267)보다 세 배 넘게 좋아 보입니다. 그러나 같은 테스트 데이터로 재면 그 트리의 R²는 0.401로 선형 회귀(0.435)보다도 낮습니다. 훈련 데이터를 통째로 외워 버려(과대적합) 처음 보는 날은 잘 맞히지 못한 것입니다. 모델 비교는 반드시 같은 테스트 데이터, 같은 지표로 해야 합니다. (참고로 이번 분할에서는 선형 회귀의 테스트 R²가 훈련 R²보다 높게 나왔는데, 테스트 날짜 73일이 우연히 직선에 더 잘 맞았기 때문입니다. 데이터가 적으면 분할에 따라 점수가 흔들리므로 L39에서 배울 교차 검증으로 보완합니다.)

Orange를 쓰는 학급은 Data Sampler(80%)로 나눈 뒤 Linear Regression·Tree·kNN을 Test and Score의 ‘Test on test data’로 평가하면 같은 공정 비교가 됩니다. 이때 ‘Test on train data’ 결과와 나란히 보여 주면 불공정 비교의 함정을 체감할 수 있습니다. 스프레드시트로는 예측값 열을 만들고 ABS·POWER·SQRT·AVERAGE 함수로 MAE·MSE·RMSE를 직접 계산해 보게 할 수 있습니다.

📌 핵심 정리

  • 통계적 회귀는 계수·p값·R²로 관계를 설명하고, 기계학습 회귀는 테스트 데이터의 오차로 예측 성능을 평가한다.
  • 같은 데이터에 선형 회귀를 적용하면 두 방법의 식은 같다. 차이는 목적·평가 방법·해석에 있다.
  • MAE·MSE·RMSE는 작을수록, R²는 클수록 좋다. RMSE는 큰 오차에 민감하다.
  • 모델 비교는 반드시 같은 테스트 데이터와 같은 지표로 한다. 훈련 데이터 점수와 테스트 점수를 섞어 비교하면 안 된다.
