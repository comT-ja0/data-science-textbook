문제 정의수집전처리탐색모델링평가·해석공유
생각 열기 “저는 수학보다 축구가 좋은데, 데이터 과학이 저랑 무슨 상관이 있나요?” 한 학생의 질문에 선생님이 웃으며 휴대 전화를 보여 주었습니다. 화면에는 한 프로 축구단의 채용 공고가 떠 있었습니다. “경기 영상과 선수 이동 데이터를 분석할 분을 찾습니다. 축구를 사랑하는 분 우대.” 좋아하는 분야와 데이터 역량이 만나면 어떤 직업이 생길까요? 오늘은 나만의 ‘데이터 진로 지도’를 그려 봅니다.

1데이터 과학이 필요한 직업들 공통 씨마스

데이터 관련 직업은 크게 두 무리로 나눌 수 있습니다. 데이터 자체를 다루는 데이터 전문 직업과, 자기 분야의 문제를 데이터로 푸는 ‘분야 + 데이터’ 융합 직업입니다. 오늘날에는 두 번째 무리가 빠르게 늘고 있습니다.

🛠️ 데이터 엔지니어

데이터를 모으고 저장·전달하는 시스템을 만든다. 데이터베이스, 클라우드, 자동화 프로그램을 다룬다.

📊 데이터 분석가

데이터를 정리·시각화해 “지금 무슨 일이 일어나고 있는가”를 설명하고 보고서로 전한다.

🤖 데이터 과학자·AI 엔지니어

통계·기계학습 모델로 앞으로 일어날 일을 예측하거나, 인공지능 서비스를 개발한다.

⚽ 스포츠 데이터 분석가

선수 이동·경기 기록을 분석해 전술과 선수 영입, 부상 예방에 도움을 준다.

🧬 생물정보학자

유전체·단백질 같은 생명 데이터를 분석해 질병 원인과 신약 후보를 찾는다.

🗺️ GIS·스마트 도시 전문가

지도·위치 데이터로 교통 흐름, 재난 위험 지역, 공공시설의 알맞은 위치를 분석한다.

이 밖에도 금융 데이터 분석가, 마케팅 데이터 분석가, 정보 보안 전문가, 데이터 시각화 디자이너, 기후 데이터 과학자, 스마트팜 전문가 등 거의 모든 분야에 데이터를 다루는 일이 있습니다. 직업 정보는 커리어넷(한국직업능력연구원 운영)이나 워크넷·고용24(고용노동부) 같은 공공 진로 정보 사이트에서 찾아볼 수 있습니다.

2데이터 직업인에게 필요한 역량 씨마스 YBM

데이터 직업인에게 필요한 역량은 흔히 알파벳 T 모양으로 설명합니다. 가로줄은 여러 분야에 두루 필요한 기본 역량, 세로줄은 한 분야의 깊은 전문성입니다.

세계경제포럼(WEF)은 2023년 「일자리의 미래」 보고서에서 앞으로 중요해질 역량으로 분석적 사고, 창의적 사고와 함께 인공지능·빅데이터 활용 능력을 꼽았습니다. 코딩 실력만이 전부가 아니라는 점에 주목하세요. 데이터에서 찾은 결과를 동료와 시민이 이해하도록 설명하는 능력, 데이터를 책임 있게 다루는 윤리 의식도 반드시 필요합니다.

3나에게 맞는 데이터 직업 찾기 YBM

진로 추천 카드 — 관심사와 강점을 고르면 직업을 추천해요

관심 분야와 자신 있는(또는 키우고 싶은) 역량을 여러 개 골라 보세요. 관심 분야 일치는 2점, 역량 일치는 1점으로 계산해 점수가 높은 직업 3개를 추천합니다.

① 관심 분야
② 자신 있는 역량

관찰 포인트: 역량만 바꾸고 관심 분야를 그대로 두면 추천이 얼마나 바뀌나요? 이 추천기는 ‘점수 규칙’이라는 아주 단순한 모델입니다. 규칙을 어떻게 바꾸면 더 좋아질까요?

추천은 출발점일 뿐 위 추천기는 교사가 정한 간단한 규칙으로 점수를 매긴 것이라 여러분의 가능성을 모두 반영하지 못합니다. 추천된 직업을 커리어넷 등에서 직접 조사해 보고, 관심이 가지 않으면 과감히 다른 직업을 찾아보세요.

4채용 공고의 핵심어 분석하기 천재

어떤 역량이 정말 많이 요구될까요? 채용 공고 같은 글도 데이터입니다. 표 형태가 아닌 비정형 텍스트 데이터이므로, 단어로 쪼개고(토큰화), 의미 없는 말을 지우고(불용어 제거), 단어마다 몇 번 나왔는지 세는(빈도 분석) 순서로 분석합니다. 단어 빈도를 글자 크기로 나타낸 그림이 워드 클라우드입니다. 아래 가상의 채용 공고 세 개로 해 봅시다.

결과를 보면 ‘데이터를’, ‘데이터’처럼 같은 단어가 조사 때문에 다르게 세어집니다. 문장 부호를 지우고 흔한 조사를 떼어 낸 뒤 다시 세어 봅시다.

세 공고 모두에서 데이터가 압도적으로 많이 나오는 것은 당연하지만, 그다음으로 파이썬·SQL·통계·전처리·시각화·소통이 두 번 이상 등장합니다. 분야는 달라도 요구하는 기본 역량은 비슷하다는 뜻입니다. 다만 공고 세 개는 표본이 너무 작으므로, 결론을 일반화하려면 훨씬 많은 공고를 모아야 합니다.

지도 팁 비코딩 반은 Orange3의 Text 애드온(Corpus → Preprocess Text → Word Cloud)이나 무료 워드 클라우드 웹 도구로 같은 활동을 할 수 있습니다. 한국어는 조사가 붙어 있어 빈칸 기준 토큰화의 한계가 분명하다는 점을 ‘전처리가 결과를 바꾼다’는 Ⅱ영역 내용의 예고로 활용하세요. 실제 채용 사이트의 공고를 대량으로 복사해 오는 활동은 이용약관을 확인하게 하고, 개인정보(담당자 연락처 등)는 지우도록 지도합니다.

📌 핵심 정리

  • 데이터 직업에는 데이터 자체를 다루는 전문 직업(엔지니어·분석가·과학자)과 ‘분야 + 데이터’ 융합 직업이 있다.
  • 데이터 직업인에게는 넓은 기본 역량(프로그래밍·통계·시각화·소통·윤리)과 한 분야의 깊은 전문성이 함께 필요하다(T자형 역량).
  • 텍스트 데이터는 토큰화 → 불용어 제거 → 빈도 분석 순서로 분석하며, 전처리 방식에 따라 결과가 달라진다.
