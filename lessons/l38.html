[12데과03-05] 데이터 분석 방법에 따른 데이터 모델의 분석 결과를 비교하고 평가한다.
문제 정의수집전처리탐색모델링평가·해석공유
생각 열기 어떤 회사가 “우리 감염병 진단 AI는 정확도 99%!”라고 광고합니다. 대단해 보이지요? 그런데 알고 보니 검사받은 1,000명 중 실제 감염자는 10명뿐이었고, 이 AI는 모든 사람에게 ‘음성’이라고 답했습니다. 990명을 맞혔으니 정확도는 정말 99%입니다. 하지만 감염자 10명은 한 명도 찾아내지 못했습니다. 이 AI는 좋은 모델일까요?

1혼동 행렬: 무엇을 어떻게 틀렸나 삼양

분류 모델을 평가할 때는 ‘몇 개 맞혔나’뿐 아니라 어떤 식으로 틀렸는지를 봐야 합니다. 실제 값과 예측 값을 교차해 네 칸으로 정리한 표를 혼동 행렬(confusion matrix)이라고 합니다. 찾고 싶은 대상(감염, 스팸 등)을 양성(Positive), 나머지를 음성(Negative)이라고 합니다.

혼동 행렬에서 네 가지 지표를 계산합니다.

지표질문계산

재현율

F1 점수정밀도와 재현율을 함께 고려하면?2 × 정밀도 × 재현율 ÷ (정밀도 + 재현율)

손으로 계산해 보기

스팸 필터가 메일 100통을 분류했더니 TP = 40, FP = 10, FN = 5, TN = 45였습니다.

  • 정확도 = (40 + 45) ÷ 100 = 0.85
  • 정밀도 = 40 ÷ (40 + 10) = 0.80 — 스팸함에 들어간 메일 5통 중 1통은 정상 메일
  • 재현율 = 40 ÷ (40 + 5) ≈ 0.889 — 스팸 45통 중 40통을 걸러 냄
  • F1 = 2 × 0.80 × 0.889 ÷ (0.80 + 0.889) ≈ 1.422 ÷ 1.689 ≈ 0.842
생각 열기의 ‘정확도 99%’ AI를 계산해 보세요 (정답 확인)
모두 음성이라고 답했으므로 TP = 0, FN = 10, FP = 0, TN = 990입니다. 정확도 = 990 ÷ 1000 = 0.99이지만, 재현율 = 0 ÷ (0 + 10) = 0입니다. 양성이 드문 불균형 데이터에서는 정확도가 모델의 실력을 크게 부풀릴 수 있으므로, 반드시 혼동 행렬과 재현율·정밀도를 함께 확인해야 합니다. (양성으로 예측한 것이 없으므로 정밀도는 계산할 수 없습니다.)

2상황에 따라 중요한 지표가 다르다 삼양

📧 스팸 필터 → 정밀도

정상 메일(합격 통지!)이 스팸함으로 가면(FP) 큰 손해입니다. 스팸 몇 통이 받은편지함에 남는 것(FN)은 참을 만합니다. 헛경보를 줄여야 합니다.

🦠 감염병 선별 검사 → 재현율

감염자를 놓치면(FN) 병이 퍼집니다. 건강한 사람이 양성으로 나오면(FP) 정밀 검사를 한 번 더 받으면 됩니다. 놓치지 않아야 합니다.

많은 분류 모델은 ‘양성일 확률(점수)’을 계산한 뒤, 점수가 임계값(threshold) 이상이면 양성으로 판정합니다. 임계값을 낮추면 양성 판정이 늘어 재현율이 오르지만 헛경보(FP)도 늘고, 임계값을 높이면 정밀도가 오르지만 놓치는 양성(FN)이 늘어납니다. 정밀도와 재현율은 보통 한쪽을 올리면 다른 쪽이 내려가는 관계입니다.

3파이썬으로 혼동 행렬 만들기 공통

L37에서 당도와 붉은정도 두 속성만으로 만든 k-NN 과일 분류 모델(테스트 정확도 0.852)을 혼동 행렬로 자세히 들여다봅시다. 세 범주 분류에서는 혼동 행렬이 3 × 3이 됩니다.

대각선(15, 16, 15)이 맞힌 개수이고, 나머지 칸이 틀린 방식입니다. 실제 사과 18개 중 3개를 귤로 잘못 분류했고, 실제 귤도 2개는 배로, 1개는 사과로 분류했습니다. 분류 보고서에서 사과는 정밀도 0.938(사과라고 한 16개 중 15개가 진짜 사과)로 높지만 재현율은 0.833(사과 18개 중 15개만 찾음)입니다. 귤과 사과를 헷갈리는 것은 두 과일의 붉은정도와 당도 범위가 겹치기 때문입니다. 보고서의 macro avg는 세 과일의 지표를 단순 평균한 값입니다.

이번에는 ‘사과인가, 아닌가’를 가리는 이진 분류를 해 봅시다. 당도 센서 하나만 있는 저렴한 선별기를 가정하고, 로지스틱 회귀로 사과일 확률을 구한 뒤 임계값을 바꿔 봅니다.

임계값을 0.3 → 0.5 → 0.7로 올리자 정밀도는 0.609 → 0.786 → 0.818로 오르고, 재현율은 0.778 → 0.611 → 0.500으로 떨어졌습니다. ‘사과를 하나도 놓치면 안 되는’ 상황이라면 0.3이, ‘사과 상자에 다른 과일이 섞이면 안 되는’ 상황이라면 0.7이 알맞습니다. 정확도는 0.5에서 0.815로 가장 높았지만, 정확도가 가장 높은 기준이 늘 목적에 맞는 기준은 아닙니다.

4모델마다 평가 방법이 다르다 씨마스

Ⅲ영역에서 배운 모델들의 평가 방법을 한눈에 정리해 봅시다. 모델이 하는 일이 다르면 ‘잘했다’를 재는 자도 다릅니다.

모델평가 지표좋은 방향주의할 점
회귀MAE, MSE, RMSE, 결정계수 R²오차 ↓, R² ↑(최대 1)R²는 ‘정확도’가 아니라 평균으로 예측할 때보다 오차를 얼마나 줄였는지(설명력)
분류정확도, 정밀도, 재현율, F1, 혼동 행렬모두 ↑(최대 1)불균형 데이터에서 정확도만 보면 속는다
군집SSE(inertia), 실루엣 계수SSE ↓, 실루엣 ↑정답이 없으므로 수치는 안내자일 뿐, 해석 가능성이 중요

  1. 각 상황에서 FP와 FN이 무엇인지 쓰고, 정밀도와 재현율 중 더 중요한 지표를 고르세요.
    상황 (양성)FP의 의미FN의 의미더 중요한 지표
    공항 보안 검색 (위험물)
    유튜브 추천 (좋아할 영상)
    신용카드 부정 사용 탐지 (부정 거래)
    학교 급식 알레르기 경고 (알레르기 유발 식품)
  2. 임계값 실험기에서 ‘감염병 선별 검사’의 재현율을 1.0으로 만드는 가장 높은 임계값을 찾고, 그때 FP가 몇 명인지 쓰세요. 이 기준을 실제로 쓴다면 어떤 추가 조치가 필요할까요?
  3. “정확도 99%” 광고를 보았을 때 꼭 물어봐야 할 질문 두 가지를 쓰세요.
지도 팁 FP·FN 용어는 학생들이 가장 많이 헷갈립니다. 뒤 글자(P/N)는 모델의 예측, 앞 글자(T/F)는 예측이 맞았는지라고 풀어 주면 좋습니다. 스프레드시트 학급은 COUNTIFS로 네 칸을 세어 지표를 계산하게 하고, Orange 학급은 Test and Score → Confusion Matrix 위젯에서 칸을 클릭해 틀린 데이터를 확인합니다. 흔한 오개념: “정확도가 높으면 무조건 좋은 모델”, “정밀도와 재현율은 동시에 올릴 수 있다(임계값만 바꾸면)”, “R²도 정확도의 한 종류”. 시간 배분: 혼동 행렬·손계산 15분, 임계값 실험기 10분, 파이썬 15분, 토론 10분.

📌 핵심 정리

  • 혼동 행렬은 실제와 예측을 교차해 TP·FP·FN·TN으로 나눈 표로, 모델이 어떤 식으로 틀렸는지 보여 준다.
  • 정확도 = (TP+TN)/전체, 정밀도 = TP/(TP+FP), 재현율 = TP/(TP+FN), F1은 정밀도와 재현율의 조화 평균이다.
  • 헛경보가 비싼 문제(스팸 필터)는 정밀도, 놓치는 것이 위험한 문제(감염병 선별)는 재현율이 중요하다.
  • 임계값을 낮추면 재현율↑·정밀도↓, 높이면 정밀도↑·재현율↓ — 목적에 맞게 정한다.
  • 회귀(MAE·RMSE·R²), 분류(정확도·정밀도·재현율·F1), 군집(SSE·실루엣), 연관(지지도·신뢰도·향상도)은 평가 지표가 다르다.
