1분류: 정답이 범주인 예측 공통

분류(classification)는 정답(레이블)이 붙은 데이터로 학습한 뒤, 새 데이터가 어느 범주에 속하는지 예측하는 지도 학습입니다. 회귀와 분류는 모두 지도 학습이지만, 예측하는 값의 형태가 다릅니다.

구분예측하는 값예
회귀연속적인 수치기온으로 자전거 대여량 예측, 공부 시간으로 점수 예측
분류정해진 범주(클래스)과일 종류(사과/배/귤), 스팸 메일 여부(예/아니오), 합격/불합격

정답이 둘 중 하나이면 이진 분류, 셋 이상이면 다중 분류라고 합니다. 오늘은 대표적인 분류 모델 두 가지를 배웁니다.

2k-최근접 이웃(k-NN): 가까운 친구에게 묻기 공통

k-최근접 이웃(k-Nearest Neighbors, k-NN)은 새 데이터와 가장 가까운 훈련 데이터 k개를 찾아, 그중 가장 많은 범주로 분류합니다(다수결 투표). 따로 규칙을 만들지 않고 훈련 데이터를 기억해 두었다가 비교하는 단순한 방법입니다.

손으로 계산해 보기

당도(brix)와 지름(cm)을 아는 과일 5개가 있습니다. 새 과일 ★(당도 12, 지름 10)은 무엇일까요?

과일당도지름종류★까지 거리
A138사과√(1² + 2²) = √5 ≈ 2.24
B129사과√(0² + 1²) = 1.00
C1111배√(1² + 1²) = √2 ≈ 1.41
D116귤√(1² + 4²) = √17 ≈ 4.12
E1010배√(2² + 0²) = 2.00
  • k = 1: 가장 가까운 B(사과) → 사과
  • k = 3: B(사과), C(배), E(배) → 배 2표, 사과 1표 → 배
  • k = 5: 사과 2표(A, B), 배 2표(C, E), 귤 1표 → 동점! 가까운 쪽을 우선하는 등 규칙이 따로 필요합니다.

k에 따라 답이 바뀝니다. k가 너무 작으면 우연히 가까이 있는 점 하나(잡음)에 휘둘리고, 너무 크면 멀리 있는 점까지 투표해 경계가 뭉개집니다. 적당한 k는 테스트 데이터나 교차 검증(L39)으로 찾습니다.

3의사결정트리: 스무고개로 분류하기 삼양 YBM

의사결정트리(decision tree)는 “무게 ≤ 151.5g인가?”처럼 예/아니오 질문을 차례로 던져 데이터를 나누는 모델입니다. 맨 위의 질문을 뿌리 노드, 마지막에 범주가 정해지는 곳을 잎 노드라고 합니다. 트리는 훈련 데이터를 가장 깔끔하게(한 범주만 남도록) 나누는 질문을 스스로 골라 가며 자랍니다.

트리의 가장 큰 장점은 사람이 읽을 수 있다는 것입니다. 선별장 직원도 그림만 보고 기계가 왜 그렇게 분류했는지 이해할 수 있습니다. 질문을 몇 단계까지 던질지를 최대 깊이(max_depth)로 정하는데, 깊이가 너무 깊으면 훈련 데이터의 사소한 차이까지 외워 새 데이터에서 틀리기 쉽습니다(과대적합, L39).

더 알아보기: 로지스틱 회귀 이름에 ‘회귀’가 들어 있지만 분류에 쓰는 모델도 있습니다. 로지스틱 회귀는 입력값으로 점수를 계산한 뒤 S자 모양의 시그모이드 함수로 0~1 사이의 확률로 바꿉니다. 예를 들어 “이 메일이 스팸일 확률 0.83”을 계산하고, 확률이 기준(보통 0.5)보다 크면 스팸으로 분류합니다. 이 기준을 바꾸면 결과가 어떻게 달라지는지는 다음 차시(L38)에서 다룹니다.

4파이썬으로 과일 분류하기 공통

fruit.csv에는 사과·배·귤 각 60개의 무게(g), 당도(brix), 지름(cm), 붉은정도(0~1)가 있습니다. 훈련 데이터 70%로 학습하고, 모델이 한 번도 보지 못한 테스트 데이터 30%로 평가합니다. stratify는 두 데이터에 과일 종류 비율을 똑같이 맞추는 옵션입니다.

당도는 7.5~15.5, 붉은정도는 0.11~1.00 범위라서 표준화하지 않으면 거리가 거의 당도로만 결정됩니다. 표준화 후 테스트 정확도가 0.759 → 0.852로 올랐습니다(테스트 과일 54개 중 41개 → 46개 정답). make_pipeline으로 표준화와 모델을 묶으면, 표준화 기준(평균·표준편차)을 훈련 데이터로만 계산하므로 테스트 데이터의 정보가 학습에 새어 들어가지 않습니다.

k = 1일 때는 훈련 정확도가 1.000(자기 자신이 가장 가까운 이웃이니까요!)인데 테스트 정확도는 0.778로 가장 낮습니다. k = 3에서 테스트 정확도 0.870으로 가장 좋았습니다. 네 속성을 모두 쓰면 테스트 54개를 모두 맞혔습니다(1.000). 이 데이터는 무게와 지름만으로도 과일이 잘 구별되기 때문입니다.

깊이 1 트리는 질문이 하나뿐이라 세 과일 중 둘만 구별할 수 있어 정확도가 0.667에 그칩니다. 깊이 2에서는 훈련 0.992, 테스트 1.000입니다. 출력된 규칙이 그림 1의 트리입니다. 속성 중요도를 보면 트리는 무게(0.512)와 붉은정도(0.488)만 사용했고, 당도와 지름은 쓰지 않았습니다. 트리는 표준화가 필요 없다는 점도 기억해 두세요. 한 속성씩 기준값과 비교할 뿐, 속성끼리 거리를 재지 않기 때문입니다.

지도 팁 k-NN은 교실에서 학생들을 ‘훈련 데이터’로 세우고 새로 들어온 학생 주변 k명에게 손을 들게 하는 몸 활동으로 도입하면 좋습니다(5분). Orange 학급은 File → Data Sampler → kNN / Tree → Test and Score로 같은 비교를 하고, Tree Viewer로 규칙을 확인합니다. 흔한 오개념: ① “k-NN도 학습 단계에서 규칙을 만든다”(훈련 데이터를 저장해 두었다가 예측할 때 거리를 계산), ② “훈련 정확도가 높으면 좋은 모델이다”(k = 1의 훈련 정확도 1.000을 보여 줄 것), ③ 군집(비지도)과 분류(지도)의 혼동 — L33의 k-평균과 k-NN은 이름만 비슷한 전혀 다른 방법임을 강조합니다.

📌 핵심 정리

  • 분류는 정답이 범주인 지도 학습이며, 회귀는 연속적인 수치를 예측한다.
  • k-NN은 가장 가까운 훈련 데이터 k개의 다수결로 분류하며, 거리를 쓰므로 표준화가 필요하고 k에 따라 결과가 달라진다.
  • 의사결정트리는 예/아니오 질문을 이어 가며 분류하고, 규칙을 사람이 읽을 수 있으며 최대 깊이로 복잡도를 조절한다.
  • 모델은 훈련에 쓰지 않은 테스트 데이터로 평가해야 하며, 표준화 기준도 훈련 데이터로만 정한다.
