3한 번에 되짚는 문제 해결 전 과정 공통

공공자전거 대여 자료(bike.csv)로 문제 해결 과정을 처음부터 끝까지 빠르게 되짚어 봅시다. 문제: “날씨와 휴일 정보로 하루 자전거 대여량을 예측해, 자전거 재배치 계획에 활용할 수 있을까?”

실행 결과를 과정별로 읽어 봅시다. 탐색: 비 온 날의 평균 대여량(2,897)은 비가 오지 않은 날(3,709)보다 적고, 기온과의 상관계수는 0.52이지만 산점도는 곡선 모양입니다. 모델링·평가: 같은 테스트 데이터에서 기온² 속성을 넣은 선형 회귀가 RMSE 428.8, R² 0.851로 깊이 4의 트리 회귀(RMSE 602.6, R² 0.706)보다 좋았습니다. 해석: 비 계수 −621.6은 “다른 조건이 같다면 비 오는 날 대여량이 약 620대 적다”는 뜻이고, 기온(+260.8)과 기온²(−7.7)의 조합은 약 17℃ 부근에서 대여량이 가장 많은 산 모양 관계를 나타냅니다. 공유: “한 도시 1년 치 가상 자료”라는 일반화 범위와 “재배치 계획에는 예측 오차(약 ±430대)만큼 여유를 둔다”는 활용 방안까지 적으면 문제 해결 과정이 완성됩니다.

지도 팁 총정리 차시는 개념 연결 카드(10분) → 종합 퀴즈(15분) → 전 과정 복습 셀(10분) → 성찰 일지(15분)로 운영하면 50분에 맞습니다. 퀴즈에서 많이 틀린 문항의 해당 차시를 사이드바에서 바로 열어 복습하게 하세요. 파이썬 복습 셀이 부담스러운 반은 Orange의 File → Feature Constructor → Test and Score(Linear Regression, Tree) 흐름으로 같은 과정을 보여 줄 수 있습니다. 성찰 일지는 인쇄해 제출받거나 포트폴리오(L55)에 넣도록 안내합니다.

4한 학기 성찰 공통

데이터 과학은 도구를 다루는 기술이면서 동시에 태도입니다. 질문을 정확히 세우는 태도, 데이터의 한계를 인정하는 태도, 예상과 다른 결과 앞에서 끝까지 원인을 찾는 태도, 그리고 분석이 사람들에게 미칠 영향을 먼저 생각하는 태도. 한 학기를 돌아보며 성찰 일지를 써 봅시다.

📌 핵심 정리

  • 데이터 과학은 ‘문제 정의 → 수집 → 전처리 → 탐색 → 모델링 → 평가·해석 → 공유’의 문제 해결 과정이다.
  • Ⅰ단원은 데이터의 이해, Ⅱ단원은 데이터 준비와 탐색, Ⅲ단원은 모델링과 평가, Ⅳ단원은 이를 실제 문제에 적용하는 프로젝트였다.
  • 좋은 분석은 두 가지 이상 방법을 공정하게 비교하고, 상관과 인과를 구분하며, 일반화 범위와 사회적 영향을 밝힌다.
  • 데이터 과학의 도구는 바뀌어도, 좋은 질문·정직한 해석·윤리적 태도는 변하지 않는다.
