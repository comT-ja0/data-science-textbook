# 데이터 과학 온라인 교과서

2022 개정 교육과정 고등학교 진로 선택 과목 **「데이터 과학」**의 성취기준 19개를 모두 반영한
학생 활동 중심 온라인 교과서입니다. **교과서 4종(삼양미디어·씨마스·와이비엠·천재교과서)을 성취기준별로 분석·통합**하여 새로 집필했으며,
**3학점(40차시)**과 **4학점(56차시)** 운영을 모두 지원합니다.

## 구성

| 단원 | 3학점 | 4학점 | 성취기준 |
|---|---:|---:|---|
| 오리엔테이션 | 1 | 1 | — |
| Ⅰ. 데이터 과학의 이해 | 7 | 10 | 12데과01-01 ~ 04 |
| Ⅱ. 데이터 준비와 분석 | 10 | 14 | 12데과02-01 ~ 04 |
| Ⅲ. 데이터 모델링과 평가 | 11 | 16 | 12데과03-01 ~ 06 |
| Ⅳ. 데이터 과학 프로젝트 | 10 | 14 | 12데과04-01 ~ 05 |
| 총정리 | 1 | 1 | 전 범위 |
| **합계** | **40** | **56** | |

왼쪽 목차 상단의 **학점 모드 스위치**로 3학점/4학점을 전환하면 확장 차시(◆) 표시와 차시 번호가 함께 바뀝니다.

### 각 차시 페이지 구성

- 📖 **본문** — 학습 목표(성취기준 명시) + 생각 열기 + 개념 설명 + 도해(SVG)
- 🕹️ **데이터 실험실 위젯** — 클릭·드래그·슬라이더로 직접 조작 (장바구니 규칙 실험실, 조인 시각화기, 표본 편향 시뮬레이터,
  IQR 울타리 계산기, 상관 산점도, 최소제곱 게임, 경사 하강법, k-평균 단계 실행기, k-NN 놀이터, 혼동 행렬 임계값 등)
- 🐍 **브라우저 파이썬 실습** — Pyodide 기반, 설치 없이 pandas·numpy·matplotlib(한글 글꼴)·scikit-learn·sqlite3 실행.
  `load_csv("파일.csv")`로 교재 데이터를 불러옵니다.
- ✍️ **학생 활동** — 개별·모둠·토론·탐구 활동 (인쇄하면 활동지 형태로 출력)
- 🧑‍🏫 **지도 팁** — Orange·스프레드시트 대안, 흔한 오개념, 시간 배분
- ✏️ **형성평가 퀴즈** — 즉시 채점 + 해설, 서술형은 예시 답안 확인

### 출판사 출처 표기

- `공통` — 4종 중 3종 이상이 함께 다루는 내용
- `삼양`·`씨마스`·`YBM`·`천재` — 해당 교과서의 특색 있는 소재·활동을 참고해 재구성한 내용

교과서별 상세 분석과 비교는 `textbook-analysis.html`(📚 교과서 4종 비교 분석)에 있습니다.

## 로컬에서 열기

정적 사이트이므로 빌드가 필요 없습니다. 파이썬 셀의 데이터 불러오기 때문에 **로컬 서버로 여는 것을 권장**합니다.

```bash
cd ds-textbook
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 에 접속합니다.

## GitHub Pages 등으로 배포

폴더 전체를 그대로 올리면 됩니다(`index.html`이 시작 페이지). 학교 방화벽에서 `cdn.jsdelivr.net`이 허용되어야
파이썬 실행 환경과 한글 글꼴을 내려받을 수 있습니다.

## 파일 구조

```
ds-textbook/
├── index.html              # 홈 (단원 안내, 문제 해결 과정, 성취기준 표)
├── textbook-analysis.html  # 교과서 4종 비교 분석 보고서 (단독 파일)
├── data.html               # 실습 데이터 안내·미리보기·내려받기
├── tools.html              # 외부 분석 도구와 데이터 포털
├── AUTHORING.md            # 차시 집필 가이드
├── LESSON_PLAN.md          # 차시별 집필 계획(교과서 4종 반영)
├── assets/
│   ├── css/style.css       # 공용 스타일
│   ├── js/common.js        # 56차시 목차(COURSE), 3/4학점 모드, 사이드바, 퀴즈 엔진
│   ├── js/pycell.js        # 브라우저 파이썬 셀 (Pyodide, load_csv, 한글 글꼴)
│   └── data/*.csv          # 교육용 가상 데이터 13종 (README.md 참고)
└── lessons/l01.html … l56.html
```

차시 내용을 고친 뒤에는 검사기로 파이썬 셀과 스크립트를 확인할 수 있습니다(Node.js 필요).

```bash
cd tools
npm install
node check_lesson.mjs ../ds-textbook/lessons/l17.html
```
