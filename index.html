데이터 과학
온라인 교과서

2022 개정 교육과정 「데이터 과학」 교과서 4종(삼양미디어·씨마스·와이비엠·천재교과서)을 성취기준별로 분석·통합하여 새로 집필한 학생 활동 중심 교재입니다. 3학점(40차시)과 4학점(56차시) 운영을 모두 지원하며, 설치 없이 브라우저에서 데이터를 직접 만지고, 파이썬으로 분석하고, 형성평가로 스스로 점검할 수 있습니다.

📚 교과서 4종 통합 📖 40차시 + 확장 16차시 🕹️ 조작형 데이터 실험실 🐍 브라우저 파이썬(pandas·scikit-learn) 🗂️ 실습 데이터 13종 ✏️ 차시별 형성평가
🎚️ 왼쪽 목차 상단에서 3학점(40차시) / 4학점(56차시) 모드를 선택하세요. 3학점 모드에서는 확장 차시가 목차에서 숨겨지고 차시 번호가 40차시 기준으로 표시됩니다.

모든 차시 상단의 단계 표시줄은 지금 배우는 내용이 데이터 과학 문제 해결 과정의 어느 단계에 해당하는지 알려 줍니다. Ⅳ단원 프로젝트에서는 이 전 과정을 모둠이 직접 수행합니다.

성취기준 한눈에 보기

이 교과서의 모든 차시는 2022 개정 교육과정(교육부 고시)의 「데이터 과학」 성취기준 19개에 연결되어 있습니다. 성취기준 코드를 누르면 해당 내용을 시작하는 차시로 이동합니다. 차시 번호는 4학점(56차시) 기준이며, 괄호는 확장 차시입니다.

출판사 표기 안내

본문과 활동 옆의 작은 태그는 그 내용이 어느 교과서의 구성·소재를 참고했는지를 나타냅니다. 공통 태그는 4종 중 3종 이상이 함께 다루는 내용, 씨마스와 같은 회색 태그는 해당 출판사 교과서의 특색 있는 소재를 참고해 재구성한 내용입니다. 모든 본문·그림·활동·데이터는 새로 집필된 오리지널 콘텐츠이며, 태그는 출처 존중과 교과서 병행 수업을 위한 참고 표시입니다. 분석 대상: 삼양미디어 · 씨마스 · 와이비엠(YBM) · 천재교과서 (가나다순) — 자세한 비교는 📚 교과서 4종 비교 분석을 보세요.

🧑‍🎓 학생

본문을 읽고 → 데이터 실험실 위젯을 직접 조작하고 → 파이썬 셀의 ▶ 실행 버튼으로 코드를 실행해 보세요. 코드 끝의 ✏️ 과제대로 값을 바꿔 다시 실행하면 더 깊이 이해할 수 있습니다. 마지막 스스로 점검하기로 이해도를 확인합니다.

🧑‍🏫 교사

목차 상단에서 학교 편제에 맞는 3학점/4학점 모드를 선택하세요. 초록색 지도 팁 상자에 도구 대안(Orange·스프레드시트)과 오개념 지도법이 있습니다. 브라우저 인쇄(Ctrl+P)를 하면 화면 요소가 정리된 활동지 형태로 출력됩니다.

💻 환경

크롬·엣지 등 최신 브라우저면 충분합니다. 파이썬 실습은 처음 실행할 때만 실행 환경(10~20MB)과 한글 글꼴을 내려받으므로 인터넷 연결이 필요합니다. 위젯과 퀴즈는 모두 즉시 동작합니다.

실습 데이터와 외부 도구 모든 실습은 교재에 포함된 🗂️ 교육용 데이터 13종으로 바로 할 수 있습니다. 공공데이터포털, Orange, 구글 코랩 등 외부 도구로 확장하는 방법은 🧰 데이터 분석 도구 모음에서 안내합니다.
