7수업 설계 시사점

학교 여건별 교과서 활용 가이드

코딩 경험이 적은 학급

천재(Orange 비코딩) 또는 씨마스의 Orange 트랙을 주교재로. Python은 씨마스 '파이썬으로 해 보기'를 선택 심화로 운영합니다. 분류 지표·엘보는 보충합니다.

정보 과목을 이수한 코딩 학급

삼양 또는 YBM. 삼양은 평가지표·교차검증까지 깊고, YBM은 손계산→코드 흐름이 친절합니다. 코드 오류를 사전에 검증하고 빈칸 노트북으로 비계를 둡니다.

크롬북·설치 제한 환경

Colab 기반 삼양·YBM이 유리합니다. Orange 교과서를 쓴다면 CODAP·구글 시트·브라우저 파이썬(본 온라인 교과서)으로 대체합니다.

씨마스(보충/심화 분기, 자기점검), 천재(6영역 루브릭), YBM(성취기준 태깅)의 평가 장치를 조합합니다.

4종 공통으로 보강해야 할 것

  1. 03-06 목적에 맞는 분석 방법 선택 — 전용 차시가 있는 교과서가 없습니다. 상황 카드 → 방법 선택 → 두 방법 비교 → 목적에 따른 최종 선택 흐름의 차시를 따로 둡니다.
  2. 공정한 모델 비교 — 같은 테스트 데이터, 같은 변수, 고정한 무작위 시드로 비교하는 습관. 데이터 누수 점검.
  3. 스케일링과 거리 — k-평균·k-NN 전에 정규화/표준화를 하고, 전후 결과를 비교합니다.
  4. 상관≠인과, 허위 상관 — 시간 추세가 같은 두 변수, 하위집단 반전(심슨의 역설)을 명시적으로 다룹니다.
  5. 04-04·04-05 — 끝까지 해결하는 태도(오류 기록·재시도 일지)와 사회적 영향·윤리 토론, 온라인 협업 기록을 프로젝트에 구조적으로 넣습니다.
  6. 자가 채점 형성평가 — 천재·삼양은 소단원 문항 세트가 없어 차시별 퀴즈가 필요합니다.
